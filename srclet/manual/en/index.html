SRCLET user guide

Start SRCLET and set your language
  1. Run ./run.sh on Linux or double-click run.bat on Windows. The first launch installs the dependencies and needs an internet connection.
  2. Open File → Settings. Choose Bosnian, English or French. Changes to the language, font sizes and icons apply immediately to open windows.
  3. Open Help → Manual or press F1 to return to this guide. Click a chapter to expand it or click a screenshot for a larger view.
Open a project or import measurements
  1. For an existing study, choose Project → Open existing project. Select a project from the list or browse to its folder.
  2. For a new study, choose Project → New project. Enter a name, choose a folder and fill in the station details. Latitude and elevation make additional methods available.
  3. Click Next and choose a TXT, TSV, CSV or XLSX file. Check the delimiter, decimal mark and column assignments in the first preview row. A year, a month and at least one measurement are required. Empty cells and -999 mark missing values.
  4. To try the workflow, open examples/methods/workflow.csv and click Save and open. The sample observations are synthetic.
Enter or correct project data
  1. Choose Enter data manually when creating a project, or Edit project data in an open project.
  2. Choose a variable and click Add column. Add one row per month. Double-click a cell to change its value. Each year and month combination must be unique.
  3. Click Save data. SRCLET checks which methods the updated observations support. The originally imported workbook is kept in the project folder.
Define an input variable or coefficient
  1. Under Customize → Parameters, choose Basic parameters for an imported measurement or Adjustable parameters for a coefficient.
  2. Click New parameter. Enter a name, a unique symbol, a unit and a description. For a coefficient, enter its default value and save the changes.
  3. Use the symbol in your input file and formula. In the method editor you can select a catalog coefficient and adjust its value for the method.
Link evapotranspiration, water balance and irrigation demand
  1. In Method selection, check the working data and date range. The list shows methods with usable measurements during that period.
  2. Select FAO-56 Penman–Monteith and click Select method. Its monthly ET₀ is now available to water balance methods. With rainfall and temperature in the data, add McCabe–Markstrom.
  3. Add the irrigation hydromodule after deriving a monthly deficit. If you have measured deficits, you can import them directly as shown in examples/mliniste.csv.
  4. Use Remove last method to try a different sequence. Click Calculate and save once you have selected the methods you need.
Add, duplicate or edit a method
  1. Open Method catalog in the project or use Customize → Methods. Select an existing record, duplicate it, or click New method.
  2. Set the group, name, symbol, unit and output. Use ET0 for monthly evapotranspiration in mm, or Deficit for monthly water deficit in mm, so subsequent methods recognise the output.
  3. For a multi-step model, enter the equations in calculation order. Set initial storage under Previous month and coefficients under Method parameters. Mark a step for publication if other methods should be able to use its result.
  4. Click Save changes. The Input data tab shows the formula inputs and example rows. For a supplied method, Export example data… saves a separate CSV file you can import into a new project.
Write and check a mathematical formula
  1. Click Edit formula… for a method or an individual calculation step. Type an expression or use the controls for fractions, roots, powers, braces and cases.
  2. Insert a symbol from the list. Enter sample values or choose an available sample month, then click Test formula. For the irrigation hydromodule, use D = 34 mm and d = 31 days.
  3. The result, 0.12694146 L/s/ha, rounds to the published 0.127 for Mlinište. Click Apply, then save the method in the catalog.
Select a frequency method and distribution
  1. Under Series for frequency analysis, choose the deficit, runoff or another available quantity. The series can come from an imported file or a water balance result.
  2. Highlight one of the six ranking methods and click Method parameters. Set the calendar month, return period in years and distribution. A ten-year return period requires at least ten years of valid observations for that month.
  3. Click Apply and then Select method. The saved result includes the estimated value, ranks and fit error. For deficit analysis it also includes the irrigation hydromodule.
Review, export and reuse results
  1. Open Saved results and choose a record by method name and timestamp. Review the output, unit and inputs used.
  2. Click Export…. Choose XLSX for an Excel table with a chart on a separate worksheet. CSV, TSV and TXT export tabular data. Frequency results include an exceedance probability chart, while monthly results use a time series.
  3. To continue a calculation, return to Method selection and pick an earlier monthly result as the working data. To change the video guide link, replace the address in video_url.txt in the application’s main folder.
